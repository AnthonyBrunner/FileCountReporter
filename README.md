# File Count Reporter
# Overview
This application will allow the user to choose a target directory from their system and then
proceed to look for all the file extensions within the directory. When finished the program 
will output all found file extensions along with the number of occurences for each one on the 
DataGrid table

# Requirements
- .net10 or newer
- windows 10 or newer

# How to use:
1) Open the application
2) Click the "Browse" button to choose the target folder
3) Once the target folder is selected, click "Select Folder" in the bottom right corner
4) Click the "Count" button and the program will begin scanning all the file extensions plus
   their number of occurences
5) Review the data provided by the program in the table
6) Click "Browse" to choose a new directory or "X" to quit
